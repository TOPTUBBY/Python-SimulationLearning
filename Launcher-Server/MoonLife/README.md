## Quick start

ดับเบิลคลิก `Launcher.bat` จากโฟลเดอร์นี้ (ต้องมี Python 3.8+ และอินเทอร์เน็ตในการเปิดครั้งแรก) ระบบดาวน์โหลดต้นฉบับไว้ใน `site/` และเปิดเว็บอัตโนมัติที่พอร์ต 8129

แถบ `TH · ไทย` / `EN · Original` อยู่ที่มุมล่างขวา **ภาษาไทยเป็นค่าเริ่มต้น** พร้อมระบบแปลเหตุการณ์ออนไลน์ซึ่งสามารถยกเลิกได้ เก็บผลแปลไว้ใน `translation_cache.json` (ไม่รวมไป GitHub)

การเปิดครั้งถัดไปจะใช้ Cache เดิม ลอง `Check_Clone.bat` หรือ `Update_Clone.bat` หากหน้าเว็บไม่ขึ้น อย่าปิด CMD ระหว่างเล่น

**IMPORTANT:** เกมนี้มีระบบภาษาเกาหลี/อังกฤษ/ญี่ปุ่นอยู่แล้ว ภาษาไทยเป็นชั้นแปลข้อความที่แสดงผลแยกต่างหาก ไม่เปลี่ยนกลไกเกมหรือ Save; การแปลออนไลน์อาศัยบริการภายนอกและไม่รับประกัน 100% ในทุกเหตุการณ์
